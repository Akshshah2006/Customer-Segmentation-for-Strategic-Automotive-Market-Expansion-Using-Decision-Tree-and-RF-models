# Customer-Segmentation-for-Strategic-Automotive-Market-Expansion-Using-Decision-Tree-and-RF-models


This project focuses on predicting customer segments for an automobile company entering new markets using machine learning techniques.

The company previously categorized customers into four segments (A, B, C, D) based on behavioral and demographic attributes. Using this historical data, we build predictive models to classify new customers into appropriate segments, enabling targeted marketing strategies.

To develop a machine learning model that accurately predicts customer segments and helps businesses perform personalized outreach in new markets.

##Models Used

Decision Tree Classifier
Random Forest Classifier
A comparative analysis is performed to evaluate model performance.

📊 Dataset
The dataset includes:

Demographic attributes (Age, Gender, etc.)
Socio-economic features (Profession, Work Experience)
Behavioral indicators (Spending Score, Family Size)
Target Variable:

Segmentation (A, B, C, D)
